To run the server:

Navigate to college_ranker directory and in the terminal, use the command-

python manage.py runserver

Server should be active and accessible at http://127.0.0.1:8000/

![server_run](https://github.com/user-attachments/assets/419af118-d1fb-49d7-9e16-fb4169b4ef28)



You will require Python and Django on your system.

Install Django by running : pip install django

Make sure you have pandas installed. If not, install it using : pip install pandas

Install required libraries: pip install geopy, <br>
                          : pip install openpyxl
